# YouTube Downloader

Multi-platform YouTube downloader project. Each supported platform is developed on its own dedicated branch.

## Platform Branches

| Platform | Branch    |
| -------- | --------- |
| iOS      | `ios`     |
| Android  | `android` |
| Windows  | `windows` |
| macOS    | `macos`   |

Switch to the branch for the platform you want to work on:

```sh
git checkout ios       # iOS
git checkout android   # Android
git checkout windows   # Windows
git checkout macos     # macOS
```
